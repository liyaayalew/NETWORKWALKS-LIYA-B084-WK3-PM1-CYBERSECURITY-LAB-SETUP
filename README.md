# NETWORKWALKS-LIYA-B084-WK3-PM1-CYBERSECURITY-LAB-SETUP
Name= Liya Mekbib

1. Downloaded and installed [John the Ripper]
2. Downloaded and installed the [Johnny GUI]
3. Openend Johnny and went to Settings.
4. Browsed to the John the Ripper 'john.exe' file in the run' folder and selected it.
5. Downloaded the encrypted practice PDF supplied with the lab.
6. Opened the [Online PDF Hash Extractor].
7. Uploaded the encrypted PDF and copyed the complete hash beginning with '$pdf$'.
8. Opened Notepad, pasted the hash, and saved the file as 'hash1.txt' for the first pdf and for the second and third as 'hash2.txt' & 'hash3.txt' respectively.Then removed any extra characters, such as 'b', if they appear before the hash.
9. Opened Johnny and selected Opened password file.
10. Choosed 'hash1.txt' for the first pdf when i finished the first then i continued to 'hash2.txt' & 'hash3.txt'.
11. Selected Start new attack and waited for the tool to finish.
12. Used the recovered password to open the practice PDF.
